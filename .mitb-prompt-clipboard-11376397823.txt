Yes, this is absolutely possible. I looked at the typosaurus `list` module and the existing `Flatten` pattern is the right approach.

Here's how it would work:

**The pattern**: typosaurus defines a `Flattened` trait that converts any type into a flat list — empty lists stay empty, leaf types become singletons (`list![Self]`), and cons cells recurse on head + tail then append. Combined with `Foldable<Concatenation>`, it flattens nested lists like `list![list![A,B], C]` → `list![A,B,C]`.

**Mapped to taxonomy**, you'd add:

1. `pub trait Flattened { type Out; }` — converts any entity into a flat `list!` of animals
2. Leaf impl: `impl<T: Animal + Species> Flattened for T { type Out = list![T]; }`
3. For each rank (`Genus`, `Family`, `Order`, `Class`, `Phylum`): `Flattened<Self::Taxa>` (recurses into the taxa list)
4. `pub type Flatten<T> = <T as Foldable<Concatenation>>::Out;`

**Your example** works naturally:
```
Flatten<list![Canus, Cat]>
→ Flattened<Canus> ⊕ Flattened<Cat>
→ Flattened<list![Dog, Wolf]> ⊕ list![Cat]
→ list![Dog, Wolf, Cat]
```

Any mix of taxonomy ranks in a single list flattens through to species automatically — `list![Canus, Mammalia]` would drill through Class → Order → Family → Genus → Species at each level.

[This is an automated reply from the **_Man in the Box_**]

Yeah, blanket impls are doable! The key insight is using a recursive marker trait to check "all elements of this list implement X":

```rust
// Marker: is this a list whose elements all implement Genus?
pub trait AllGenus {}
impl AllGenus for Empty {}
impl<H: Genus, T: AllGenus> AllGenus for List<(H, T)> {}

// Blanket impl: any list of genera is a family
impl<T: AllGenus> Family for T {
type Taxa = T;
}
```

Same pattern for each rank:
- `AllSpecies` → blanket impl of `Genus` for any list of species
- `AllGenus` → blanket impl of `Family` for any list of genera
- `AllFamily` → blanket impl of `Order` for any list of families
- etc.

This lets you skip named types entirely:

```jungle
// Instead of defining `struct Canis` + `impl Genus for Canis`:
list![Dog, Wolf]  // automatically a Genus (via AllSpecies)
list![list![Dog, Wolf], Cat]  // automatically a Family → flattens to [Dog, Wolf, Cat]
```

**Tradeoff**: adds a few marker trait definitions per rank (boilerplate), but usage becomes much more ergonomic — no named structs needed for every genus/family/order. The `Flattened` + `Foldable<Concatenation>` machinery stays the same and handles the mixed-rank flattening automatically.
