# Welcome to the Jungle

This is an example application that renders the progression of several `jungle` `Animal`s playing a rendition of "Welcome to the Jungle," the opening track for Guns N' Roses debut album Appetite for Destruction (1987).

All timing and notation data is contained within the `Flow` types themselves, their associated const generics, or the state over which they operate. Raw PCM audio (including voice synthesis) is generated by the `Effect`s and then rendered by [cpal](https://github.com/RustAudio/cpal).

```
cargo run --example welcome --release --features viewer,audio,video,vocals,bass,drums,leadguitar,rhythmguitar
```

Also see the [lyrebird](../lyrebird/) example which uses `jungle` to generate the instrument code featured here by [Monte Carlo Tree Search](https://en.wikipedia.org/wiki/Monte_Carlo_tree_search).

The 5-second, 480p (standard definition), animal video overlays are originally from the Planet Earth series, and property of BBC.

The Guns N' Roses song "Welcome to the Jungle," originally published by Axl Rose, Slash, Duff McKagan, and Izzy Stradlin, is property of Universal Music Publishing Group under the label Geffen Records.

The notation for "Welcome to the Jungle" used here is adapted from "Welcome to the Jungle v5," which was uploaded to [onlinesequencer.net](https://onlinesequencer.net) by AuroraSonica.
